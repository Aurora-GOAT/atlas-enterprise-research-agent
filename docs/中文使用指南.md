# Atlas 企业研究Agent：中文使用指南

## 最方便的Windows启动方法

1. 安装 **Python 3.11 或 3.12**（安装时勾选“Add Python to PATH”）。
2. 将整个项目ZIP解压到电脑上的普通文件夹。
3. 双击根目录的 **`start_windows.bat`**，首次会自动安装所需Python包（需要联网）。
4. 浏览器访问 **http://127.0.0.1:8000**。
5. 点击“加载合成演示资料”，在输入框选择“模拟投资尽调”，然后点击“开始研究”。
6. 切换到“质量评估”页面，运行10条合成测试样例；研究页面可导出Markdown报告。

如果双击窗口闪退：打开PowerShell，在项目根目录执行 `python -m pip install -r requirements.txt`，再执行 `python run.py`，查看报错提示。

## 默认不需要API Key

离线模式不调用任何商业大模型，而是基于本地资料进行可追溯检索，适合演示产品流程和来源核验。

可选大模型增强需要你自行在本机环境变量设置 `OPENAI_API_KEY`，且只有在界面开启“大模型辅助总结”时才会向相应模型接口发送检索片段。**不要把任何API Key或雇主保密文件上传GitHub。**

## 和小红书RPT岗位的对应关系

- **企业场景与用户洞察**：见 `docs/PRD.md`，注意用户问题仍属于待验证假设，不要虚构访谈结果。
- **Agent工作流设计**：任务拆解、文档搜索、证据登记、报告、人工核验。
- **原型落地**：完整Web UI、FastAPI接口、批量文档解析、数值工具调用。
- **效果评价**：10条合成标注样例，Hit@3、MRR及可复现测试。
- **作品证明**：GitHub代码、测试文件、界面截图、PRD、产品架构及演示指南。
